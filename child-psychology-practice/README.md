# Child Psychology Practice Lab

An interactive, single-file practice dashboard for Child Psychology (23MSPSY3CNOD01, MSc Psychology Semester III, Jain University).

Open `index.html` in any browser. No install or build is needed.

## What it does

1. **Dashboard:** five colour-coded module cards (Modules I–V) with their syllabus topics, progress per module and best scores.
2. **Set up:** pick a module, optionally filter by topic, choose MCQ or descriptive practice, set the number of questions (10, 20, 30, 50 or all) and shuffle.
3. **MCQ practice:** 100 MCQs per module (500 in total), one at a time. A correct answer shows 😊 with positive feedback. An incorrect answer shows "Better luck next time" with the correct answer and an explanation. Includes a question navigator, progress bar, live score, restart and change-module controls, and keyboard shortcuts.
4. **Results:** score, percentage, correct, incorrect and unanswered totals, score by topic, **key concepts to remember** for each topic covered in the test, questions to revisit, and an option to retry missed questions.
5. **Descriptive practice:** 50 exam-style questions (10 per module) with a large answer box and autosaved drafts. "Check my answer" shows a model answer outline as a checklist (with an approximate key-term check), a four-part self-assessment rubric (accuracy, coverage, clarity, examples) and an estimated self-score. This is self-assessment, not AI grading.

Progress and drafts are stored in the browser's localStorage only. Module V questions draw on standard developmental psychology knowledge for the listed syllabus topics.
